All integration cards should have the same compact height and shape. Show a consistent plus/minus control that reveals lower details when opened. Keep account name and connection status visible, and do not stretch neighboring compact cards when another card expands.

Expanded cards must cover both grid columns horizontally and push the remaining
integrations down; keep a single column on phones.

**Why:** The user explicitly requested that the opened integration cover both boxes
and move the other integrations below it.
