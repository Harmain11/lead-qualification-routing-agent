---
name: Dashboard selection submission
description: Personal View selections on Dashboard and Analytics stay staged until an explicit submit applies them.
---

Dashboard and Analytics Personal View checkbox changes are drafts. Do not change which plots/cards are rendered or persist the new selection until the user submits. Keep the currently applied selection visible while they edit, and indicate when the draft differs.

**Why:** The user asked to select the plots they need, then submit before the selected plots appear.

**How to apply:** Keep separate draft and applied selections for Dashboard and Analytics; submit copies the draft into the applied selection and saves it to the device.
