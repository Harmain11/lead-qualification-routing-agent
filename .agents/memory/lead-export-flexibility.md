---
name: Lead export flexibility
description: Product expectations for selecting fields in lead exports to match destination import schemas.
---

Let users choose which lead fields to include in supported export formats so the file can match an external import schema.

**Why:** Different CRM and import workflows require different fields; the user requested choosing columns for alignment.

**How to apply:** Apply the selected, allowlisted fields consistently across renderers and preserve existing export compatibility and safety protections.
