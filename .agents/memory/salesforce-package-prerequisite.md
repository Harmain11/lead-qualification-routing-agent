---
name: Salesforce package prerequisite
description: User-required package installation before connecting Salesforce.
---

The user requires the Salesforce package to be installed before connecting
Salesforce and wants the installer and required steps presented when Connect is
clicked.

Package installer:
https://login.salesforce.com/packaging/installPackage.apexp?p0=04taj000000j95Z

**Why:** The user identified installation as a prerequisite, rather than another
OAuth policy change.

**How to apply:** Keep this prerequisite in Connect, Reconnect and setup guidance.
Installation must be in the same Salesforce organization being authorized.
User confirmation is not proof of installation; do not claim opening the link
verifies installation or that it guarantees OAuth success.
